# BiblioTech - Sistema de Gestión de Biblioteca Universitaria

Este proyecto es una plataforma web responsiva diseñada para el control, administración y reserva de libros en una biblioteca. Cuenta con un diseño minimalista estético basado en colores pasteles.

## 🚀 Requisitos Funcionales Implementados
1. **Autenticación Estricta:** Control de accesos con roles diferenciados para Lectores (Clientes) y Bibliotecarios (Staff).
2. **Modelo Relacional:** Arquitectura basada en 4 modelos principales (`Libro`, `Autor`, `Categoria`, `Prestamo`).
3. **Operaciones CRUD:** Panel de control operativo para la manipulación completa del catálogo en línea.
4. **Dashboard Estadístico:** Métricas en tiempo real acompañadas de dos gráficos dinámicos interactivos.
5. **Módulo Transaccional:** Sistema automatizado de reservas con cálculo de vencimientos a 7 días y devolución física de ejemplares.
6. **Reportes:** Botón nativo de descarga para exportación de inventarios en formato compatible con Excel.
